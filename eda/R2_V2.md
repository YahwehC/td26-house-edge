## Change and fitting provenance

The r2_v1 structural priors are retained, including pairs (1,4), (2,6), (3,8),
size lag tied to the first pair member, and peer lag 3. Exact sparse inference
remains disabled: the earlier r2_variants experiments did not support enabling it.

1. A fixed 11-coefficient global logit model and one common binary weather amplitude
   are calibrated from released target probabilities. The model family and penalty
   are the existing main-v10 procedure (`ev68.calibrate`), with no hyperparameter sweep.
   Every reported adaptation prediction excludes that adaptation episode's targets
   from calibration: three episode folds. Released main-round target episodes are
   included in every fold, sharing non-temporal coefficients across rounds while the
   machine-specific lag structure remains adaptation-specific. Final test parameters
   refit this fixed model on all released main/adaptation target episodes.
2. Persistent machine offset variance 0.04 is selected on adaptation TRAIN histories.
   Stable machines use first 60% of ticks for offset fitting and final 40% for outcome
   scoring. Variances 0/.04/.09 give Brier .08777877/.08762829/.08770673; .04 delta
   -.00015048, episode-cluster SE .00009620, 15/24 original episodes improve.
   Weather covariates use other machines and strictly previous ticks. Latent structural
   labels are inferred from full histories; this is a component check, not a wholly
   future-blind end-to-end backtest.
3. The legacy 10% generic fallback is removed. Adaptation stable-train pseudo forecasts
   independently sample 24 older ticks for each machine plus 40 recent ticks, with
   prediction cutoffs at least 192. All three original-episode folds select main weight
   1.0. Brier delta -.00094260 vs .9 main weight, cluster SE .00038934; 18/24 improve.
   Predictions remain isolated by `(episode, machine)`, avoiding the prior window-pooling
   issue. Available source history limits the upper cutoff tail.

The original base priors and size vectors retain r2_v1's train+validation provenance.
The calibration report is OOF for the new supervised global coefficients; it is not a
fully independent holdout for every inherited component or for the whole research process.
This entry uses validation targets in calibration, unlike r2_v1's train-history-only
global checkpoint. Do not describe r2_v2 as fitted exclusively on training data.

## Reproduction and delivery checks

Offline fit scripts, in order:

```
.venv\Scripts\python.exe eda/r2_calibration.py
.venv\Scripts\python.exe eda/r2_offset_train.py
.venv\Scripts\python.exe eda/r2_blend_train.py
.venv\Scripts\python.exe eda/r2_selected_validation.py
.venv\Scripts\python.exe eda/r2_pooled_calibration.py
.venv\Scripts\python.exe eda/build_r2_v2.py
```

Offline calibration uses NumPy/SciPy. Submitted inference is pure standard library.
The build uses the normal `build_entry.py` with `--data kit2_x/public` and matching
r2_v2 params, CSV and ZIP paths. Extracted ZIP prediction under Python 3.13 matches
all 1,536 CSV rows with maximum absolute difference **0**. CSV format checks pass.
Dense and short adaptation histories pass normalization and exact future-tick
exclusion tests (`test_global_state.py ... dense/short kit2_x/public`).

Packaged `train.py` refits the base priors and preserves the offline global checkpoint,
metadata and explicit peer lag; this is not an end-to-end offline calibration rerun.
Under Python 3.13 it produces a parameter JSON exactly equal to the submitted one.
The package README states this distinction. No competition form was submitted.
